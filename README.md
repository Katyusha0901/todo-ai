# To-Do List

Приложение на React, TypeScript и Vite: добавление, выполнение, редактирование и удаление задач, удаление всего списка. Задачи сохраняются в localStorage браузера. Редактирование поддерживает сохранение и отмену (кнопкой или Escape).

## Запуск

```sh
npm install
npm run dev
```

Откройте адрес из терминала (обычно http://localhost:5173).

## Сборка и просмотр

```sh
npm run build
npm run preview
```

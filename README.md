# To-Do List

Минималистичное веб-приложение для управления повседневными задачами, разработанное с использованием AI-инструментов в рамках тестового задания на позицию Vibe Coder.

**[Открыть приложение](https://katyusha0901.github.io/todo-ai/)**

## Функциональность

- Добавление новых задач
- Отметка задач как выполненных
- Редактирование задач с возможностью сохранения и отмены
- Удаление отдельных задач и очистка всего списка
- Подсчёт активных и выполненных задач
- Сохранение задач в localStorage после обновления страницы
- Адаптивный интерфейс для мобильных и десктопных устройств

## Технологии

- **React** — компонентный интерфейс и управление состоянием
- **TypeScript** — типизация данных и компонентов
- **Vite** — сборка и локальная разработка
- **CSS** — стилизация и адаптивная вёрстка
- **localStorage** — хранение задач в браузере

## Разработка с AI

Проект разработан с использованием **OpenAI Codex в VS Code**.

AI применялся для инициализации проекта, генерации компонентов, реализации функциональности, стилизации интерфейса и рефакторинга кода.

Архитектура приложения, требования к функциональности и дизайну определялись самостоятельно. Сгенерированный код анализировался, дорабатывался и проверялся вручную.

Разработка велась поэтапно:

1. Постановка задачи и проектирование архитектуры
2. Генерация кода с помощью AI
3. Анализ и проверка результата
4. Рефакторинг и исправление замечаний
5. Тестирование и публикация

## Локальный запуск

```bash
git clone https://github.com/Katyusha0901/todo-ai.git
cd todo-ai
npm install
npm run dev
```

После запуска приложение будет доступно по локальному адресу, указанному в терминале.

## Сборка

```bash
npm run build
```

Для предварительного просмотра сборки:

```bash
npm run preview
```
